# Demo samples

`demo_input/`  7 invented files: registration CSV (two patients with the same name), English discharge summary,
Hindi prescription, visitor log with an unlisted (canary-style) name, OPD JSON with PII in a key and a path,
plus a truncated JSON and a fake JPEG that must be quarantined.
`demo_output/` what Raksha writes for them (regenerated by the script).

Run and check everything:

    bash samples/check_samples.sh

Note: with only 3 patients, the rare-value rule generalises the single hypertension diagnosis to its ICD chapter.
